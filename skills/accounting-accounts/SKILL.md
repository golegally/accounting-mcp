# Accounts

- `accounts_get_accounts`: List all accounts
- `accounts_create_account`: Create a new account
- `accounts_bulk_delete_accounts`: Delete multiple accounts
- `accounts_get_account_transactions`: Retrieve account transactions (GL ledger entries)
- `accounts_get_account_types`: Get all account types
- `accounts_validate_bulk_delete_accounts`: Validate which accounts can be deleted
- `accounts_get_account`: Get account details
- `accounts_edit_account`: Edit an existing account
- `accounts_delete_account`: Delete an account
- `accounts_activate_account`: Activate an account
- `accounts_inactivate_account`: Inactivate an account
