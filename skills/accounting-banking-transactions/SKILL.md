# Banking transactions

- `banking_get_transaction`: Get a single bank transaction
- `banking_delete_transaction`: Delete a bank transaction
- `bank_categorization_categorize`: Categorise a bank line
- `banking_exclude_transaction`: Exclude a bank transaction from reconciliation
- `banking_match_transaction`: Match a bank transaction to a GL reference
- `banking_restore_transaction`: Restore an excluded transaction back to pending
- `bank_categorization_uncategorize`: Undo a bank line's categorisation
- `banking_unmatch_transaction`: Unmatch a bank transaction
- `banking_list_transactions`: List bank transactions with filtering
- `banking_create_transaction`: Create a manual bank transaction
- `banking_delete_import_batch`: Delete all transactions from a CSV import batch
