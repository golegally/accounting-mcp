# Banking

- `banking_list_bank_accounts`: List all bank accounts
- `banking_create_bank_account`: Create a bank account for reconciliation
- `banking_get_bank_account`: Get bank account by ID
- `banking_edit_bank_account`: Edit a bank account
- `banking_delete_bank_account`: Delete a bank account (only if no transactions)
- `bank_entries_get_entry`: A bank entry
- `banking_list_rules`: List bank rules
- `banking_create_rule`: Create a bank rule
- `banking_get_rule`: Get a bank rule
- `banking_edit_rule`: Edit a bank rule
- `banking_delete_rule`: Delete a bank rule
