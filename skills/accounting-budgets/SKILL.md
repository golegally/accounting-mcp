# Budgets

- `budgets_get_budgets`: List budgets
- `budgets_create_budget`: Create a budget (draft)
- `budgets_get_budget`: Get budget with entries
- `budgets_edit_budget`: Edit budget metadata
- `budgets_delete_budget`: Delete a budget (draft only)
- `budgets_activate_budget`: Activate a budget (draft → active)
- `budgets_close_budget`: Close a budget (active → closed)
- `budgets_upsert_entries`: Bulk upsert budget entries
- `budgets_get_variance_report`: Budget vs actuals variance report
