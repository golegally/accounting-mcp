# Bundles

- `bundles_get_bundles`: List bundles
- `bundles_create_bundle`: Create a new bundle
- `bundles_get_bundle`: Get bundle by ID
- `bundles_edit_bundle`: Update a bundle
- `bundles_delete_bundle`: Delete a bundle
- `bundles_activate_bundle`: Activate a bundle
- `bundles_inactivate_bundle`: Inactivate a bundle
- `bundles_list_bundle_prices`: List prices attached to a bundle
- `bundles_set_prices`: Replace all prices attached to a bundle (idempotent)
- `bundles_attach_price`: Attach a price to a bundle
- `bundles_detach_price`: Detach a price from a bundle
