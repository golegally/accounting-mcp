# Coupons

- `coupons_list_coupons`: List coupons
- `coupons_create_coupon`: Create a coupon
- `coupons_apply_coupon`: Apply a coupon, counting the redemption
- `coupons_validate_coupon`: Check whether a coupon code may be used, without redeeming it
- `coupons_get_coupon`: Get one coupon
- `coupons_update_coupon`: Update a coupon
- `coupons_delete_coupon`: Delete a coupon
