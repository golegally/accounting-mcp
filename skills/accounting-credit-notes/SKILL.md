# Credit Notes

- `credit_notes_get_credit_notes`: List all credit notes
- `credit_notes_create_credit_note`: Create a new credit note
- `credit_notes_bulk_delete_credit_notes`: Delete multiple credit notes
- `credit_notes_validate_bulk_delete_credit_notes`: Validate which credit notes can be deleted
- `credit_notes_get_credit_note`: Get credit note details
- `credit_notes_edit_credit_note`: Edit a credit note
- `credit_notes_delete_credit_note`: Delete a credit note
- `credit_notes_get_applied_invoices`: List applied invoices for a credit note
- `credit_notes_delete_apply_credit_note_to_invoice`: Delete an applied credit note from an invoice
- `credit_notes_apply_credit_note_to_invoices`: Apply credit note to invoices
- `credit_notes_open_credit_note`: Open (publish) a credit note
- `credit_notes_create_refund`: Create a credit note refund
- `credit_notes_delete_refund`: Delete a credit note refund
- `credit_notes_get_refunds`: List credit note refunds
- `credit_notes_void_credit_note`: Void an open credit note
