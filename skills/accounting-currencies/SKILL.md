# Currencies

- `currencies_get_currencies`: Retrieve all currencies
- `currencies_create_currency`: Create a new currency
- `currencies_get_exchange_rates`: List exchange rates with optional filtering
- `currencies_create_exchange_rate`: Create a new exchange rate entry
- `currencies_convert_amount`: Convert an amount between currencies
- `currencies_get_latest_rate`: Get the exchange rate for a currency on a date
- `currencies_edit_exchange_rate`: Edit an exchange rate entry
- `currencies_delete_exchange_rate`: Delete an exchange rate entry
- `currencies_delete_currency`: Delete a currency by code (cannot delete base currency)
- `currencies_get_currency`: Get currency by ISO 4217 code
- `currencies_edit_currency`: Edit a currency by ID
