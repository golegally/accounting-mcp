# Currency Revaluation

- `currency_revaluation_list`: List all revaluations for the organization
- `currency_revaluation_preview`: Preview revaluation without posting (dry run)
- `currency_revaluation_run`: Run currency revaluation and post GL entries
- `currency_revaluation_get_by_id`: Get revaluation with entry details
- `currency_revaluation_reverse`: Reverse a previously posted revaluation
