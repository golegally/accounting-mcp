# Entitlements

- `customer_entitlements_of_reference`: Get the entitlements of a customer known by their reference
- `customer_entitlements_of_customer`: Get a customer's entitlements
- `entitlement_defaults_list`: List default plans
- `features_list`: List features
- `features_create`: Create a feature
- `features_edit`: Edit a feature
- `product_features_set_default_plan`: Make a product its brand's default plan, or not
- `product_features_get`: Get what a product includes
- `product_features_replace`: Set what a product includes
