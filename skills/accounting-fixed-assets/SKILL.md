# Fixed Assets

- `fixed_assets_list`: List fixed assets
- `fixed_assets_create`: Register a fixed asset
- `fixed_assets_run_depreciation`: Charge depreciation
- `fixed_assets_register`: Fixed asset register
- `fixed_assets_list_types`: List asset types
- `fixed_assets_create_type`: Add an asset type
- `fixed_assets_get`: Get a fixed asset
- `fixed_assets_remove`: Delete a fixed asset
- `fixed_assets_add_addition`: Add to an asset's cost
- `fixed_assets_dispose`: Dispose of a fixed asset
