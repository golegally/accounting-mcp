# India GST

- `india_gst_get_gst_profile`: Get org GST profile
- `india_gst_save_gst_profile`: Save org GST profile
- `india_gst_get_gstr1`: GSTR-1 return data
- `india_gst_export_gstr1`: Prepare GSTR-1 as Excel (GSTN template)
- `india_gst_get_gstr3_b`: GSTR-3B return data
- `india_gst_hsn_search`: Search HSN/SAC codes
- `india_gst_hsn_status`: HSN/SAC sync status
- `india_gst_hsn_sync`: Sync HSN/SAC codes from CBIC
- `india_gst_hsn_get`: Get HSN/SAC code details
- `india_gst_get_lut`: Get LUT status
- `india_gst_save_lut`: Save LUT details
- `india_gst_tds_entry_list`: List TDS entries
