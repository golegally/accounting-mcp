# Opening balances

- `opening_balances_get`: Get the opening balances
- `opening_balances_set_accounts`: Set the accounts' opening balances
- `opening_balances_add_bill`: Carry in an open bill
- `opening_balances_remove_bill`: Remove an opening bill
- `opening_balances_set_migration_date`: Set the migration date
- `opening_balances_add_invoice`: Carry in an open invoice
- `opening_balances_remove_invoice`: Remove an opening invoice
- `opening_balances_set_stock`: Set the opening stock
