# Payment Receives

- `invoice_payments_get_invoice_payments`: List all payments
- `invoice_payments_create_invoice_payment`: Create a new payment received
- `invoice_payments_bulk_delete_invoice_payments`: Delete multiple payments
- `invoice_payments_get_tax_withheld_register`: Tax customers withheld from their payments
- `invoice_payments_validate_bulk_delete_invoice_payments`: Validate which payments can be deleted
- `invoice_payments_get_invoice_payment`: Get payment received details with entries
- `invoice_payments_edit_invoice_payment`: Edit the given payment received
- `invoice_payments_delete_invoice_payment`: Delete the given payment received
- `invoice_payments_get_invoice_payment_invoices`: Retrieve sale invoices linked to a payment received
