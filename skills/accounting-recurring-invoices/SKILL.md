# Recurring Invoices

- `recurring_invoices_list`: List recurring invoice templates
- `recurring_invoices_create`: Create a recurring invoice template
- `recurring_invoices_get`: Get a recurring invoice template by ID
- `recurring_invoices_edit`: Edit a recurring invoice template
- `recurring_invoices_delete`: Delete a recurring invoice template
- `recurring_invoices_pause`: Pause an active recurring invoice template
- `recurring_invoices_resume`: Resume a paused recurring invoice template
- `recurring_invoices_stop`: Stop a recurring invoice template for good
