# Recurring Journals

- `recurring_journals_list`: List recurring journal templates
- `recurring_journals_create`: Create a recurring journal template
- `recurring_journals_get`: Get a recurring journal template by ID
- `recurring_journals_edit`: Edit a recurring journal template
- `recurring_journals_delete`: Delete a recurring journal template
- `recurring_journals_pause`: Pause an active recurring journal template
- `recurring_journals_resume`: Resume a paused recurring journal template
