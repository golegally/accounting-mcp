# Subscription Add-ons

- `subscription_addons_list_all_addons`: List all add-ons for a subscription (pending + billed history)
- `subscription_addons_list_pending_addons`: List only pending (unbilled) add-ons for a subscription (paginated)
- `subscription_addons_cancel_addon`: Cancel a pending add-on (only works if not yet billed)
