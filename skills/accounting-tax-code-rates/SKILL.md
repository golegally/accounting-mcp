# Tax Code Rates

- `tax_code_rates_list`: The rates of the organization's tax codes, per country and period
- `tax_code_rates_create`: Give a tax code a rate in a country from a day
- `tax_code_rates_update`: End a tax code rate, or change its reverse-charge accounts
- `tax_code_rates_remove`: Delete a tax code rate
