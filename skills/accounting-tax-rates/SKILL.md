# Tax Rates

- `tax_rates_get_tax_rates`: Retrieves the tax rates
- `tax_rates_create_tax_rate`: Create a new tax rate
- `tax_rates_bulk_delete_tax_rates`: Delete multiple tax rates

- `tax_rates_edit_tax_rate`: Edit the given tax rate
- `tax_rates_delete_tax_rate`: Delete the given tax rate
- `tax_rates_activate_tax_rate`: Activate the given tax rate
- `tax_rates_inactivate_tax_rate`: Inactivate the given tax rate
