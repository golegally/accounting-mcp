# Transactions Locking

- `transactions_locking_get_transaction_locking_meta_list`: Get all transactions locking meta
- `transactions_locking_cancel_transaction_locking`: Cancel all transactions locking for a module or all modules
- `transactions_locking_cancel_partial_unlocking`: Cancel partial unlocking all transactions locking for a module or all modules
- `transactions_locking_command_transactions_locking`: Lock all transactions for a module or all modules
- `transactions_locking_unlock_transactions_locking_between_period`: Partial unlock all transactions locking for a module or all modules
- `transactions_locking_get_transaction_locking_meta`: Get transactions locking meta for a module
